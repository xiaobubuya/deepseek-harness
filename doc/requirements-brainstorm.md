# AI Agent Server 需求文档

## 项目背景

PhotoCraft 和 LightCraft 提供了功能强大的照片编辑 CLI，但普通用户难以直接使用命令行。本项目构建一个 AI Agent Server，通过自然语言对话驱动 PhotoCraft CLI，让用户用对话的方式完成照片编辑，并将操作实时反馈到 muyaya.world/photocraft/ 前端。

## 核心目标

用户用自然语言描述照片编辑需求，AI Agent 自动调用 PhotoCraft CLI 完成操作，结果实时反馈到前端。

## 技术决策（已确认）

| 决策项 | 选择 | 说明 |
|--------|------|------|
| 用户认证 | 简单密钥鉴权 | 开放版，API Key 控制访问 |
| 中间数据 | 不存储 | 处理过程中的中间状态不持久化 |
| 图片存储 | 存储 | 上传和处理后的图片保存到服务器 |
| 并发限制 | 不限制 | 不做并发控制 |
| 图片大小 | 不限制 | 不限制上传大小 |
| 图片格式 | 按 PhotoCraft 支持 | 沿用 PhotoCraft CLI 的格式支持 |
| 成本控制 | 不控制 | 不限制 API 调用次数 |
| LLM 模型 | sensenova-6.8-flash-lite | 通过 CI 参数注入 API Key |
| LLM 地址 | https://token.sensenova.cn/v1 | 阿里云 OpenAI 兼容接口 |

## 功能需求

### 1. 自然语言理解
- 接收用户自然语言指令（如"把天空调蓝"、"给照片加暖色调"）
- 解析为 PhotoCraft CLI 命令序列
- 支持多步骤操作（如"先降噪，再锐化，最后调对比度"）
- 支持中文和英文指令
- 支持模糊描述（如"让照片看起来更专业"→ 多步操作）

### 2. CLI 执行引擎
- 调用 PhotoCraft CLI 执行编辑操作
- 支持批量处理（多张图片）
- 支持进度回调（每步操作完成后回调）
- 支持错误处理（命令失败时返回错误信息）
- 支持超时控制（防止长时间运行）

### 3. 实时反馈
- WebSocket 推送操作进度
- 实时显示当前步骤
- 显示处理百分比
- 推送预览图（处理后的图片）
- 推送日志信息
- 推送错误信息

### 4. 前端集成
- 集成到 muyaya.world/photocraft/ 页面
- 聊天界面（输入指令、显示进度、显示结果）
- 图片上传界面
- 结果预览界面
- 支持 iframe 嵌入

### 5. 部署
- 部署到百度云服务器（120.48.86.101）
- 使用 DeepSeek Harness 框架
- 支持自动部署（CI/CD，GitHub Actions）
- 支持健康检查
- 支持日志收集

## 非功能需求

### 性能
- 首次响应时间 < 5 秒
- 图片处理时间 < 60 秒（普通照片）
- 内存占用 < 512MB
- 启动时间 < 10 秒

### 可靠性
- 服务崩溃后自动重启
- 图片数据不丢失
- 支持健康检查端点

### 安全
- API Key 鉴权
- 文件类型验证（仅允许图片格式）
- 命令注入防护（白名单命令）

## 验收标准

1. 用户输入"把天空调蓝"，系统自动调用 CLI 完成操作
2. 操作过程中，WebSocket 实时推送进度
3. 操作完成后，前端显示结果预览
4. 支持错误处理和友好提示
5. API Key 鉴权正常工作
6. 服务崩溃后自动重启
7. CI/CD 自动部署到服务器
